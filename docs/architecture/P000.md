# P-000 Architecture

P-000 is an independent practice-lab foundation. Templates are immutable source records; instantiation copies permitted account structure into an attempt. All student changes live under that attempt. Journal lines in integer cents are the sole financial facts, and reports are projections.

The pure accounting package has no HTTP, Prisma, or UI imports. The API supplies authenticated identity and never accepts a student ID from request data. Owned-attempt lookup returns the same not-found result for absent and foreign records. Composite database foreign keys prevent cross-attempt entry/account references. Domain validation and a deferred PostgreSQL constraint trigger independently reject imbalance atomically.

Instructor fields reside in columns that student queries must never select. Student response types and `studentView` contain no instructor-capable field. Errors use fixed messages and no source metadata. Locked documents expose only IDs after their action threshold; their content is retrieved separately after authorization and unlock verification.

Reset preserves history by sealing the old generation and creating a new empty attempt. Append-only action rows record creation, posting, unlocking, and reset. The single fictional fixture proves structure only and is not P-001 content.
